# Task 2 — типизированная форма и валидация

Форма редактирования курса. Значения полей, ошибки и результат валидации
описаны типами, а `onSave` получает уже проверенный `Course`.

## Что внутри

- `types.ts` — `Course`, `CourseEditFormProps`, `FormValues` (поля как строки),
  `FormErrors` (необязательные сообщения) и результат валидации
  `ValidResult | InvalidResult`, различаемый по полю `ok`.
- `lib/validateCourseForm.ts` — обрезает пробелы, проверяет, что название не
  пустое, а места — целое число от 0; при успехе возвращает `seats` уже как `number`.
- `CourseEditForm` — хранит `values` и `errors`, на сабмите вызывает валидацию
  и либо показывает ошибки, либо вызывает `onSave({ ...course, title, seats })`.
- `App` — держит текущий курс в `useState<Course>` и показывает сохранённую запись как JSON.

## Что проверяем

| Действие | Результат |
| --- | --- |
| Очищаем название и жмём «Сохранить» | «Название не может быть пустым», поле подсвечено |
| Вводим в места `-1`, `2.5` или `abc` | «Места — целое число от 0…» |
| Вводим корректные данные | Ошибки пропадают, JSON обновляется, `seats` — число |
