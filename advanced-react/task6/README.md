# Task 6 — управляемый и неуправляемый компоненты

Два фильтра курсов по названию: один хранит значение поля в стейте, другой читает его
из DOM через `ref` только по кнопке.

## Что внутри

- `ControlledFilter` — управляемый `input`: значение в `useState`, список фильтруется
  на каждый ввод. Кнопка «Сбросить» очищает стейт.
- `UncontrolledFilter` — неуправляемый `input` с `defaultValue` и `useRef`. Значение
  попадает в стейт только по кнопке «Применить»; «Сбросить» очищает поле через `ref`
  и возвращает на него фокус.
- `CoursesList` — список курсов из `courses.json`, отфильтрованный по `query`;
  если ничего не нашлось — «Ничего не найдено».
- Оба поля обёрнуты в `<label>` с видимой подписью — `placeholder` её не заменяет.

## Что проверяем

| Действие | Что увидим |
| --- | --- |
| Печатать в первом фильтре | Список под ним обновляется сразу |
| Печатать во втором фильтре | Список не меняется |
| **Применить** | Список фильтруется по введённому тексту |
| **Сбросить** | Поле очищается, показываются все курсы |

## Запуск

```bash
npm install
npm run dev
```
