# Task 2 — ререндеры списка и localStorage

Задача показывает, что при обновлении состояния родителя перерендериваются **все**
дочерние карточки, и проверяет, что выбор курса сохраняется в `localStorage`.

## Что внутри

- `App` — счётчик, кнопка проверки `localStorage` и список курсов из `courses.json`.
- `CourseCard` — карточка курса. Логирует каждый свой рендер, по кнопке «Выбрать»
  записывает `id` курса в `localStorage` под ключом `selected-course`.

## Что проверяем (смотри консоль)

| Действие | Что увидим | Вывод |
| --- | --- | --- |
| **Изменить render** | `[render] CourseCard <id>` для каждой карточки | Изменение state в `App` перерендеривает весь список, хотя пропсы карточек не менялись |
| **Выбрать** | `[click] записан id: <id>` | `id` курса записан в `localStorage`, ререндера при этом нет — state не менялся |
| **Проверка localStorage** | `[check] localStorage <id>` | Значение сохранилось и переживает перезагрузку страницы |

> В dev-режиме `StrictMode` вызывает рендер дважды, поэтому `[render]` логи дублируются.

## Запуск

```bash
npm install
npm run dev
```
