# Task 5 — композиция через слоты

Универсальный компонент `Panel` принимает разметку через пропсы-слоты и не знает,
что именно внутри: фильтр или карточка курса.

## Что внутри

- `Panel` — секция с тремя слотами: `title` (заголовок), `children` (тело) и
  необязательный `actions` (кнопки). Заголовок связан с секцией через `useId` +
  `aria-labelledby`.
- `App` — панель фильтра по категории с кнопкой сброса, строка с выбранным курсом
  и список курсов из `courses.json`, каждый в своей `Panel` с кнопкой «Выбрать курс».

## Что проверяем

| Действие | Что увидим |
| --- | --- |
| Выбрать категорию в селекте | В списке остаются только курсы этой категории |
| **Сбросить фильтры** | Снова показываются все курсы |
| **Выбрать курс** | В строке «Выбран» появляется `id` курса |

## Запуск

```bash
npm install
npm run dev
```
