# Task 9 — useMemo

Сортировка большого списка (2000 курсов) с замером времени. Сравниваем
компонент, который сортирует на каждом рендере, и компонент с `useMemo`.

## Что внутри

- `coursesDouble.ts` — 2000 курсов, сгенерированных из `courses.json`.
- `sortedCourse.ts` — сортировка по названию или местам, ASC/DESC; время
  пишется в консоль как `[sort] <ключ> <направление>: N мс`.
- `ListWithoutMemo` — вызывает сортировку прямо в рендере.
- `ListWithMemo` — оборачивает сортировку в `useMemo` с зависимостями
  `[items, sortKey, direction]`.
- `CourseTable` — показывает первые 10 курсов.
- `App` — переключатель `useMemo`, выбор сортировки и несвязанный счётчик.

## Что проверяем

| Действие | Что увидим в консоли |
| --- | --- |
| Без `useMemo` жмём «Несвязанный счётчик» | `[sort] …` на каждый клик |
| С `useMemo` жмём «Несвязанный счётчик» | Новых `[sort]` нет |
| Меняем поле или направление сортировки | `[sort] …` в обоих режимах |

## Запуск

```bash
npm install
npm run dev
```
