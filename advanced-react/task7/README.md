# Task 7 — Container / View

Логика и отображение разделены: контейнер хранит стейт и фильтрует данные,
View только рисует то, что ему передали через пропсы.

## Что внутри

- `CourseCatalogContainer` — контейнер: стейт поиска и выбранного курса, фильтрация
  `courses.json` по названию. Передаёт во View готовый список, текст пустого
  состояния и `onSelect`.
- `CourseListView` — презентационный компонент без стейта: получает `items`,
  `emptyText` и `onSelect`. Если список пуст — показывает `emptyText`.
- `App` — контейнер и тот же `CourseListView` отдельно: с полным списком и с пустым
  массивом (выбор пишется в консоль).

## Что проверяем

| Действие | Что увидим |
| --- | --- |
| Печатать в поле «Поиск» | Список в контейнере фильтруется |
| Запрос без совпадений | «По запросу ничего не найдено» |
| **Выбрать** в контейнере | В строке «Выбран» появляется `id` курса |
| **Выбрать** в блоке «полный список» | В консоли `[onSelect] <id>` |
| Блок «пустой массив» | «Курсов нет» |

## Запуск

```bash
npm install
npm run dev
```
