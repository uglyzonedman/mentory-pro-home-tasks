# Task 8 — Подъём состояния

Всё состояние живёт в `App`, дочерние компоненты получают значения и колбэки
через пропсы и сами ничего не хранят.

## Что внутри

- `App` — хранит `query`, `category` и `selectedId`, фильтрует `courses.json`
  по названию и категории, показывает количество найденных и выбранный курс.
- `FilterPanel` — поле поиска, select категории и кнопка «Сбросить фильтры».
  Значения и обработчики приходят из `App`.
- `CourseListView` — презентационный список из task7: `items`, `emptyText`, `onSelect`.

## Что проверяем

| Действие | Что увидим |
| --- | --- |
| Печатать в поле «Поиск» | Список фильтруется, «Найдено» обновляется |
| Выбрать категорию | Остаются только курсы этой категории |
| Поиск + категория | Работают вместе |
| **Сбросить фильтры** | Поиск очищается, категория — «Все» |
| **Выбрать** у курса | В строке «Выбран» появляется `id` курса |

## Запуск

```bash
npm install
npm run dev
```
